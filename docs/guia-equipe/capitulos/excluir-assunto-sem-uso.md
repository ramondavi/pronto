# Excluir um assunto sem uso

**Resultado:** remover permanentemente um assunto que não está ligado a protocolo. **Para quem:** equipe ativa com permissão de gestão de assuntos. Esta ação não serve para corrigir duplicidade nem para retirar temporariamente um assunto de novas escolhas.

## Elementos desta tarefa

| Elemento no Pronto! | O que faz |
| --- | --- |
| **Administração → Assuntos** | Localiza o registro e mostra sua situação e número de protocolos. |
| **Ver autoridade** | Permite conferir o registro completo antes da decisão. |
| **Editar** | Permite corrigir a forma ou revisar a autoridade sem excluir. |
| **Mesclar** | Trata duplicidade com revisão e histórico, quando aplicável. |
| **Desativar** | Retira o assunto das novas escolhas sem apagar fichas anteriores. |
| **Excluir** | Abre a confirmação de exclusão permanente quando o uso é zero. |
| **Excluir assunto / Cancelar** | Confirma a remoção ou preserva o registro. |

## Quando usar

Use somente para um registro criado por engano, sem uso em protocolos, depois de conferir que não há forma, fonte ou vínculo que deva ser preservado. Para duplicidade, prefira **Mesclar**; para impedir novas escolhas mantendo histórico, use **Desativar**.

## Passo a passo

1. Em **Assuntos**, localize a forma preferida e confira o contador de **protocolos**. O botão **Excluir** só aparece para assunto sem uso e não mesclado.
2. Abra **Ver autoridade** para conferir origem, variantes, relações e fontes. Compare com registros semelhantes antes de decidir; confira também se há apresentação pública que precisará ser retirada por outro procedimento.
3. Se a exclusão ainda for adequada, selecione **Excluir**. Leia a janela **Excluir “nome do assunto”?**, que informa a permanência da ação. Use **Cancelar** se houver dúvida ou necessidade de preservar o registro.
4. Selecione **Excluir assunto** e aguarde a lista atualizar. Faça nova busca pela forma para confirmar a remoção. Uma falha não comprova exclusão; atualize a lista e confira o registro antes de repetir.

## Impedimentos e continuidade

A interface não oferece **Excluir** quando o contador de uso é maior que zero. Não contorne essa regra no banco: fichas e históricos precisam permanecer íntegros. Um atendimento aberto também pode impedir alterações no cadastro. Se a intenção é substituir um termo usado, siga o procedimento **Mesclar assuntos duplicados**; para cessar uso futuro, siga **Alterar situação do assunto**.

> **Captura a inserir:** cartão de assunto fictício com **0 protocolos** e botão **Excluir**; outra captura da confirmação **Excluir assunto**, sem registrar uma exclusão real só para obter a imagem.
