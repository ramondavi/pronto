Quando usar este procedimento

Use este guia quando seu protocolo em Minhas solicitações mostrar Correção solicitada. A Biblioteca indica os campos que precisa conferir novamente; os demais permanecem protegidos.

Elementos que você vai usar

Elemento no Pronto!O que fazer nele
Minhas solicitaçõesLocalize o protocolo e leia sua situação atual.
Correção solicitadaIndica que a Biblioteca aguarda sua resposta.
Corrigir campo pendente ou Corrigir campos pendentesAbre somente os campos devolvidos para correção.
Reenviar correção ou Reenviar correçõesEnvia os valores corrigidos à Biblioteca quando todos os campos pedidos estão prontos.

Passo a passo

  1. Entre em Minhas solicitações e confira o protocolo com a situação Correção solicitada.
  2. Use Corrigir campo pendente ou Corrigir campos pendentes, conforme a quantidade de itens devolvidos.
  3. Em cada campo, leia Orientação da biblioteca e, quando houver, Observação complementar. Compare o valor atual com o trabalho final e altere somente o que foi solicitado.
  4. Se a pendência for o acesso ao PDF e o endereço continuar igual, confirme no formulário que corrigiu o acesso e que a Biblioteca já pode abrir o arquivo.
  5. Quando todos os campos solicitados estiverem prontos, selecione Reenviar correção ou Reenviar correções.

Como conferir o resultado

Volte ao protocolo em Minhas solicitações e acompanhe a nova análise. O reenvio entrega os ajustes para conferência; ele não aprova automaticamente os dados nem libera a ficha.

Se o botão de reenvio estiver indisponível

Confira quais campos ainda mostram pendência. Para cada um, siga a orientação da Biblioteca e verifique se o valor foi realmente alterado ou, no caso do mesmo link, se a confirmação de acesso foi marcada. Se o problema persistir, use a ajuda do painel com o número do protocolo.
